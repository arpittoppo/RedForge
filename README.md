# RedForge

> Forge Your Red Team Workflow.

RedForge is an open-source, Python-based Red Team Operations Workbench designed to help security professionals organize engagements, manage evidence, document findings, and generate professional reports.

## 🚀 Vision

Build a modern, cross-platform desktop application that supports the entire lifecycle of a red team engagement.

## Features (Planned)

- Engagement Management
- Target Management
- Evidence Manager
- Findings Database
- Report Generator
- MITRE ATT&CK Explorer
- Threat Intelligence
- Local AI Assistant
- Plugin System
- Secure Credential Vault

## Technology Stack

- Python
- PySide6
- SQLAlchemy
- SQLite
- Ruff
- pytest
